Sequence:
	1. Nodes send Advertising Data
	2. Pi Hub sends connection request
	3. Nodes awnser with connection response
		Nodes are connected
	
	
	Environment Nodes send environment data to Hub
	Hub calculates appropiate actions
	Hub sends Actions to Actuator Node
	Actuator Node 
	
	
Data struct:

uint8_t node_id
uint8_t msg_type
uint16_t sequence_number
uint16_t payload[16]
